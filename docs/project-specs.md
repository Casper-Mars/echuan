# 项目需求与多技术方案

一个项目对应一条需求。需求文档保持一条版本链；技术方案可以有多份，每份具有稳定编号（如 `APP-1-S0001`）和独立版本链。标题和正文一起修订，历史内容只追加、不覆盖。本轮不包含 Word/PDF 上传、附件系统、删除方案或逐文档审批。

## 保存与评审

`project_specs.material_id` 持有独立方案当前版本；`materials.previous_material_id` 向前连接该文档历史。方案列表、全文及历史由 `GET /v1/specs` 读取；创建用 `POST /v1/specs`，修订用 `PATCH /v1/specs?id=方案编号`。修订必须带该独立文档版本的 `If-Match`，历史版本只能读取、下载。

只在项目处于规格评审（1）或规划中（2）时允许新建、修订方案。批准仍以项目为单位，针对全部当前方案；没有每份文档单独批准的状态。任意方案保存都会递增项目版本，使已打开页面的旧项目评审版本失效；进入任务清单评审及后续阶段后，不开放方案修改。保持原有需求编辑状态限制和项目状态迁移。

## 项目资料包与旧接口

`projects.spec_material_id` 不再指向汇总包，而是指向**最后提交的那一份方案版本**。保存方案时只写这一份文档，不再读取其他方案、不再拼接「技术方案包」，资料库里也不会新增名为 `*技术方案包` 的资料。

完整资料通过 `GET /v1/projects/package?id=项目编号` 按需下载：服务端把需求当前版本和每份方案当前版本现拼成 zip，每份文档一个 Markdown 文件（如 `需求-v3-登录页改版.md`、`方案-S0001-v2-接口设计.md`）。zip 只在内存中生成，不落库、不移动指针；无需求且无方案时返回零条目的合法 zip（200）。中文文件名用 RFC 5987 的 `filename*` 传递。

旧 `GET /v1/projects?id=` 的 `spec`、旧 `GET /v1/projects/materials?kind=2`、Worker 领取上下文的 `spec_version/spec_digest` 都指向该单份方案文档。需要全部当前方案时改用资料包接口。**项目详情已不再返回 `requirement_md` 与 `spec_excerpt`**，正文一律走 `GET /v1/materials?id=`；网页对独立文档另有全文阅读入口。

旧 `POST /v1/projects/specs?id=项目编号` 修订第 1 份独立方案，而不是用一个文档替换全部集合。返回的 `spec` 和 `previous_material_id` 指向本次提交的该份文档版本及其前一版。旧调用未传标题时沿用项目标题这一既有行为。

所有任务使用所属项目的 `spec` 指针（最后提交的一份方案）；未加入按任务绑定特定方案的机制，也不再把全部方案拼进任务上下文。领取接口、Worker 心跳与 kit 无需更改字段；查看独立文档可用 `/v1/specs`，下载完整集合用资料包接口。

## 详情与正文分离

`GET /v1/projects?id=` 只返回索引与元数据：`requirement` / `spec` 两个资料引用（含 `material_id`），不返回 `requirement_md`、`spec_excerpt`。正文的唯一通道是 `GET /v1/materials?id=资料编号`（按内容寻址、带 `Cache-Control: immutable`）。写需求的请求体仍用 `requirement_md` / `body_md`，写通道不受影响。

这样详情响应与需求长度无关（38 万字需求下恒定在 1 KB 量级），前端 5 秒轮询不再重复搬运正文，服务端也不再为详情请求读磁盘。`detail()` 因此少了两次文件 IO 与一个失败面：资料文件缺失时详情仍能正常返回。

## 迁移与一致性

迁移 `0004` 将旧单方案及整条旧链作为第 1 份独立方案回填，保留资料编号、文件和版本。新表具备内部 `id`、稳定 `spec_id`、项目归属、序号、当前资料指针、创建及更新时间。

独立文档和项目版本在同一写事务保存。每份文档受 `material_max_bytes` 限制（默认 20 MiB），超限整笔拒绝、不落任何资料。失败仅清理本次新建对象，不删除既有共享对象。项目取消不会删除这些资料；具有方案的项目沿用原有不可直接删除约束。

## 网页操作

项目详情不再内联正文，只给需求版本链与资料元信息（含 `material_id`），正文按需下载或阅读；新增技术方案列表。“新建技术方案”创建一份独立文档；“阅读全文”打开完整正文与版本选择；当前版可编辑，历史版只读并可下载。“项目资料包”按钮下载需求与全部方案的当前版本；“方案提交历史”展示方案指针所在的版本链，每版仍可单独下载。
